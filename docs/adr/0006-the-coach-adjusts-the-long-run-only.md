# The coach adjusts the Long Run only

Whether the AI coach evaluates a Run is decided by its Run Type, and the only
kind it evaluates is the Long Run (#176). The Easy Run and the Quality Run are
recorded in full, count toward history and the 30-day load, and are never
adjusted — the coach is not even asked about them.

Before this, the coach decided by asking whether the Run just finished had
run/walk Intervals — a proxy for "is this a Run I understand". Once a Stage
offers one Workout of each Run Type that proxy fails in both directions: a
continuous Easy Run has no walks and would be skipped, and a Quality Run does
have them and *would* be evaluated. The coach would start adjusting the one
session that most wants leaving alone.

The Long Run is where the judgement is genuinely worth making. Whether this
week's endurance run goes from 30 minutes of running to 36 depends on how the
last few went, which is exactly the kind of question a coach is for. An Easy Run
is a fixed continuous stretch and a Quality Run a fixed set of strides; there is
nothing there to weigh.

## Consequences

- **The Quality Run never progresses on its own.** Six strides until it is
  changed by hand. Accepted, not overlooked: a static rule taking it toward
  eight belongs in its own ticket, and an AI does not belong in it at all.
- **A Prescription is floored at the Stage's own Workout of the same Run Type,**
  not at the Stage's first. In Stage 1 the first Workout *is* the Long run, so
  the two agreed by accident until this was written down.
- **In a Stage offering no Long run the coach says nothing at all** — no
  Prescription and no debrief, because it is never asked. Stage 3 is two hard
  days, so that is where it lands; it is still locked, so nobody is there yet.
- **A Stage that offers no Workout of the finished Run's kind gets no
  Prescription.** Reachable only when the plan or Stage moves while the coach is
  being asked, which takes seconds. Flooring a Long Prescription at a stride
  session, or at nothing, would be the Plan rewritten into a shape nobody asked
  for. The debrief still stands — it is about the Run just finished.
- **A Run that followed no Workout has no Run Type,** so it is not evaluated.
  That is the same outcome the old proxy gave an unplanned Run, by a rule that
  says why.
